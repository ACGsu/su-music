# Su Music

Windows x64 音乐播放器，当前版本 `0.4.0-rc.2`。支持标准版酷狗扫码登录与网易云公开 UID 连接、单账号视图切换、只读歌单同步、公开分享导入（支持酷狗与网易云歌单）、在线网易云搜索与搜索历史、歌单即时过滤、内嵌版本选择、播放队列、本地音频和自选歌曲缓存目录。

本文同时包含使用说明和开发入口。实际覆盖与限制见 [docs/KNOWN_LIMITATIONS.md](docs/KNOWN_LIMITATIONS.md)，第三方来源见 [licenses/THIRD_PARTY_NOTICES.md](licenses/THIRD_PARTY_NOTICES.md)，源码维护约束见 [docs/AGENT.md](docs/AGENT.md)。

## 安装与启动

运行 `release/0.4.0-rc.2/Su-Music-0.4.0-rc.2-x64-setup.exe`，选择安装目录，再启动 Su Music。安装面向当前 Windows 用户。升级前关闭正在运行的 Su Music；使用同一 Windows 用户可继续读取本机曲库、外观、版本选择和缓存目录设置。

免安装使用可运行 `release/0.4.0-rc.2/Su-Music-0.4.0-rc.2-x64-portable.exe`。首次运行会在 Portable EXE 旁创建 `Data/`，移动或备份时需要将 EXE 与 `Data/` 一起复制。也可直接运行 `release/0.4.0-rc.2/win-unpacked/Su Music.exe`，该目录版仍使用 `%APPDATA%\Su Music\`。

首次启动是空曲库。已有账号曲库保存在本机，启动后可先浏览。发行目录提供本说明、`docs/`、`licenses/` 及校验文件；本版本在当前 Windows 11 x64 环境验收，其他系统范围见 `docs/KNOWN_LIMITATIONS.md`。

## 连接账号与导入歌单

统一账号中心在“账号与设置”中管理酷狗与网易云两个账号，并支持在侧栏快速切换单账号视图：

1. **酷狗账号**：点击扫码登录，使用标准版酷狗扫描二维码并在手机确认。登录后自动读取默认、自建和收藏歌单；重新启动恢复会话后也会同步。需要核对新收藏时点击同步。
2. **网易云账号**：输入 1–18 位公开纯数字 UID 连接。首次连接自动同步该用户的公开歌单（包括我喜欢的音乐、自建歌单和收藏歌单），此后仅在用户点击时手动刷新。不保存任何密码或 Cookie 凭据，无法读取私密歌单，也不支持云端编辑或增删收藏。
3. **账号切换**：侧栏底部账号状态按钮可一键在酷狗与网易云之间切换。切换时停止当前播放并清空队列，隔离两者的播放历史、本地绑定与置顶歌单；公开分享导入的歌单在两边视图中均可见。
4. 在“我的歌单”按默认、自建、收藏分类浏览，也可筛选歌单名、切换网格或列表，并将常用歌单固定到侧栏。

退出登录、登录失效或同步失败时，上一次成功读取的本机曲库保留。同步只读取对应平台公开内容；增删收藏、修改歌单或顺序请在原平台完成。

公开分享歌单可在“我的歌单”的分享导入入口提交酷狗分享链接或网易云歌单链接（支持移动端/PC端链接及短链），导入后单列展示。歌单封面优先采用歌单本身的封面图（经主进程受控下载并缩放），缺图时使用第一首歌曲图片或文字占位；网格完整显示图片。

## 播放、队列与版本选择

在歌单点击“播放歌单”，或双击一首歌开始播放。单击歌曲行可在该行下方直接展开内嵌操作区域（一次仅展开一行，再次点击或按空格键折叠/展开；双击或按 Enter 播放该行；已匹配行右侧提供“播放”和“下一首播放”快捷按钮）。底部可暂停、切歌、拖动进度、调整音量，以及切换顺序、随机、单曲循环模式。打开队列可调整顺序或移除曲目。播放队列与曲目时长在程序关闭后持久保存，重新启动时自动维持上一次播放的歌单曲目、当前歌曲与对应时长，处于就绪待播放状态（不自动播放声音），点击播放或双击任一歌曲即可继续播放。

元数据匹配的同版本直接尝试播放；网易云曲库歌曲自动直接绑定原曲 ID，无需重新按标题搜索。资料不足、版本有差异或时长冲突时，在内嵌操作区打开“版本对照”核对歌手、专辑、版本和时长，再操作：

| 操作 | 结果 |
| --- | --- |
| 选定并播放 | 保存本机选择，并将歌单显示为选定的曲名、歌手、专辑和时长；同步、重排及重启继续保留选择。 |
| 仅试听 | 播放此次候选，歌单显示和已保存的选择保持原状态。 |
| 更换版本 | 展开歌曲行的内嵌操作，再次打开版本对照。 |
| 恢复原版 | 撤销该位置的本机选择，恢复收藏记录的显示并尝试原版。 |
| 关联本地音频 | 选择本机 MP3、FLAC 或 WAV 文件作为该曲目的播放版本。 |

本机选择保留原始收藏；云端不发生更改。重复歌曲按歌单中的每个位置分别保存选择。“播放历史”和“正在播放”显示实际播放的版本。浏览其他页面、切换昼夜或关闭面板时，播放与队列保持连续。

匹配成功只表示资料符合规则，最终播放仍取决于实际资源。失败曲目会显示原因并进入“待处理歌曲”，可重试、换版本或关联本地文件。

## 搜索与本地音乐

顶栏搜索栏支持点击或按 `Ctrl+K` 唤出下拉浮层，自动聚焦输入框，保留最近 20 条搜索历史（可单条删除或一键清空全部，点击历史项立即执行搜索）。

全局搜索固定搜索在线网易云音源，每页 20 首，触底无限滚动加载，加载失败时支持点击重试；搜索结果可播放或查看版本。

歌单内查找使用歌单详情页右上角的即时过滤输入框（内存实时匹配曲名、文件名、歌手、专辑、版本，展示过滤数量，纯展示不影响播放队列）。

“本地音乐”中可添加 MP3、FLAC、WAV，单独播放或加入队列。移出列表保留原文件；文件被移动、删除或改写后，需要重新添加或关联。“播放历史”保留最近 200 条实际播放记录，纯浏览和解析失败不记作播放。

## 自选缓存目录

打开“账号与设置 → 歌曲缓存 → 选择目录”，选择希望存放歌曲缓存的位置。普通目录下会使用专用的 `Su Music Cache` 子目录；重启保留该设置。默认位置为 `%APPDATA%\Su Music\Audio Cache`。

切换目录后，当前歌曲继续使用原资源，后续歌曲使用新位置；旧目录缓存保留。点击“恢复默认目录”可回到默认位置，“清理歌曲缓存”处理当前目录中的应用缓存并保留正在使用的文件。曲库、登录资料和版本选择保存在账号资料目录，不随歌曲缓存目录迁移。

完整缓存总量上限为 2 GB，单首上限为 512 MB。未下载完整的内容不会作为完整缓存重播。缓存不是批量下载入口；尚未缓存的在线歌曲需要联网。

## 键盘与外观

| 按键或设置 | 用途 |
| --- | --- |
| Ctrl+K | 唤出搜索浮层并聚焦输入框。 |
| Tab / Shift+Tab | 在可操作控件之间移动焦点。 |
| Enter | 激活焦点按钮；焦点位于歌曲行时播放该位置。 |
| 空格 | 歌曲行有焦点时展开／折叠行内操作面板，页面其他有焦点时暂停／继续；输入框和按钮保持各自的按键行为。 |
| Escape | 关闭搜索浮层、队列、版本面板或许可对话框。 |
| 外观 | 选择跟随系统、白天、黑夜。 |
| 列表密度 | 选择舒适或紧凑；与网格／列表设置一同保留。 |

工业风外观在黑夜模式下主按钮采用强调色 `#FFFA00` 黄底配深色文字与黑色左边缘指示条；在白天模式下采用深色底白字配黄色左边缘指示条。

## 常见状态

| 界面状态 | 下一步 |
| --- | --- |
| 二维码已失效 | 重新生成二维码，再用手机扫码。 |
| 会话失效 | 重新扫码登录；本机缓存曲库仍可查看。 |
| 同步失败 | 保持现有曲库，检查网络后重试同步。 |
| 需要对照版本 | 核对候选资料，再选定、试听或关联本地音频。 |
| 原版暂不可用 | 重试资源，或接受另一版本、本地文件。 |
| 请求额度暂时用尽 | 等候界面所示的可重试时间；避免连续强制刷新。 |
| 缓存目录不可写 | 换一个可写目录或恢复默认目录；在线资源可继续尝试。 |
| 本地文件缺失或已改变 | 重新添加或关联文件。 |

安装版账号资料位于 `%APPDATA%\Su Music\`，Portable 版账号资料位于其旁边的 `Data/`。升级及普通卸载保留资料；备份时先关闭应用，并另行保存自选缓存和本地音频。许可与来源可在“账号与设置”查看，也随发行文件提供。

“账号与设置 → 软件更新”可手动检查 [ACGsu/su-music](https://github.com/ACGsu/su-music) 的 GitHub Release。应用不会后台检查或自动下载；发现更高版本后，由用户点击“一键更新”。安装版只使用对应 NSIS 安装包，Portable 版只替换对应 Portable EXE，下载完成前会核对随 Release 提供的 SHA-256 文件。预发布版本会继续接收预发布及正式更新，正式版本只接收正式更新。

## 开发

开始修改前先阅读 [docs/AGENT.md](docs/AGENT.md)，其中列明各脚本的用途。开发文档集中在 `docs/`，许可与第三方声明集中在 `licenses/`；根目录保留 README 和工具链直接使用的配置文件。

使用固定的 Node.js 24.19.0 和 pnpm 11.22.0，从项目根目录执行：

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node scripts/prepare-electron.mjs
node scripts/audit-licenses.mjs
pnpm dev
```

Electron 固定为 45.2.3，运行时下载与解压独立校验；安装生命周期脚本默认关闭。SQLite 使用 Node／Electron 自带的 `node:sqlite`。

## 检查与打包

```powershell
node scripts/check.mjs
node scripts/package.mjs
node scripts/audit-package.mjs
```

检查包括主进程／Vue 类型和构建；本机存在单元测试时一并执行，缺少 `tests/` 时明确记录跳过测试。`tests/`（含样本及 `tests/scripts/` 中的回归、安装验证与诊断脚本）仅保存在本机，不随 Git 提交，也不打包；从 Git 检出的源码可直接构建，但不包含这些测试资料。

本机单元测试使用 `pnpm test`。`pnpm smoke` 与 `pnpm smoke:desktop` 是同一个桌面回归入口，任选一个即可；按导入与安全、账号、播放、布局执行一次完整计划。首次启动和恢复分别检查，布局覆盖 100%／125%／150% 三档缩放，排序和快捷键等功能检查仅执行一次。覆盖归属及去重说明见 [docs/TESTING.md](docs/TESTING.md)。

可用 `node scripts/test.mjs --desktop --list` 预览计划，`--suite=playback` 选择单组，`--scale=1.25` 指定布局缩放。`node scripts/test.mjs --dev` 验证 Vite 开发模式的导入与安全。发行程序重新构建、打包后使用 `node scripts/test.mjs --desktop --packaged`，随后运行 `node scripts/audit-package.mjs --smoke`；旧版安装包须先重建，不能套用新的测试结果。

所有测试结果和工具缓存集中到被 Git 忽略的 `.tmp/`。桌面测试成功后自动删除本轮截图、模拟数据库和音频，只保留各运行模式的一份最新摘要；失败时保留本轮资料供诊断。加 `--keep-artifacts` 可保留成功资料。单元测试自动删除自身资料；真实网络验证仍需单独运行。

发行目录取自 `package.json` 的版本号，当前为 `release/0.4.0-rc.2/`。同一版本重新打包更新该目录，版本升级创建新版本目录，已有版本保留。一次打包同时生成 NSIS 安装包和 Portable EXE，但不自动发布或上传；README、开发说明、限制和许可按源码中的目录结构随包提供，审计为两种交付文件分别生成 SHA-256。隔离安装验证及其他开发命令见 `docs/AGENT.md`。

## 数据与 Git

安装版资料位于 `%APPDATA%\Su Music\`；Portable 版资料位于 Portable EXE 旁的 `Data/`，包括曲库、偏好、本机版本选择、历史及 Windows 加密会话。Windows 加密会话换电脑或 Windows 用户后可能需要重新登录；自选缓存和本地音乐使用绝对路径，不随 Portable 目录自动迁移。渲染进程没有 Node、任意文件／网络接口或凭据访问；GD 请求共享 45 次／5 分钟预算，酷狗凭据不发送音源服务。

Git 保留 `src/`、`scripts/`、`docs/`、`licenses/`、构建配置、锁文件、图标与 README。`tests/`、`node_modules/`、临时结果、安装包、编译产物、日志和私人资料不提交。历史阶段报告、V0 验证器和旧发行产物已清理；后续开发使用 `docs/AGENT.md`，本机回归不依赖这些历史文件。
