# Su Music 实际覆盖与已知限制

版本：0.5.0-rc.2 · 更新日期：2026-11-24

## 已验收的范围

## 音源与版本

- 当前播放来源为 GD 的网易云音源，本地 MP3、FLAC、WAV，以及已保存的完整歌曲缓存；没有已验证的独立在线备用服务。
- 能搜索到候选、取得地址或读到音频头部，不能证明与收藏的是同一完整录音，也不代表所有 VIP 歌曲可播放。
- 相同标题、歌手、版本标签且时长差不超过 2 秒时可自动选择；多个同版本候选优先同专辑、接近时长。元数据仍可能标注错误，用户可更换版本。
- 音质优先尝试 320 kbps，以实际返回或音频头部为准；接口可能降级、过期或暂时不可用。
- GD 搜索、元数据补充及播放地址解析共用每 5 分钟 45 次的额度记录；频繁强制刷新可能需要等待。

## 账号与同步

- 支持标准版酷狗扫码登录和网易云公开 UID 连接，均为只读同步。
- 酷狗与网易云各保留一个账号配置，曲库采用单账号视图；侧栏可快速切换账号，切换时停止旧账号播放并隔离播放历史、版本绑定与歌单置顶，公开分享歌单在两边保持共享展示。
- 网易云使用公开纯数字 UID 读取公开歌单（包含默认我喜欢的音乐、自建歌单及收藏歌单）；无法读取私密歌单或私人云盘，不具备任何云端编辑、收藏增删或写入能力，不保存密码或 Cookie 凭据。首次连接自动同步，此后仅在用户手动点击时刷新。
- 网易云歌单超过 1000 首时支持自动分批增量拉取完整曲目详情；若遇到平台下架、失效或已删除歌曲导致数量微小差异，采用柔性校验导入实际有效曲目并在界面提示差异，单个歌单异常独立隔离，不中断全局曲库同步。
- 网易云歌曲直接绑定原曲 ID 播放，无需按标题搜索，但仍受限于 GD 音源可用性及版权限制；同步时保留用户手动选择的版本与本地文件。
- 酷狗收藏专辑暂放在收藏歌单分类，并保留专辑类型。普通他人收藏歌单的真实子类型尚无样本，不声称已跨账号、跨子类型通用验证。
- 真实手机拒绝确认已观察；服务器自然二维码过期、长期会话及刷新能力仍未完整实测。此前两处 hash 变化原因按用户要求免除复测，原记录保留。
- 第三方接口可能改变。当前短期通过不等于长期稳定性已获证明；失败时保留上次完整成功的本机曲库；网易云退出登录后同样保留本机已同步曲库。
- 本机版本选择跟随原歌曲及各重复位置。元数据、hash 或顺序变更的保留已测试；原歌曲从曲库移除后，不会把其选择转给另一首歌。

## 歌单定位、快捷键与缓存

- 歌单右侧当前曲目按钮暂停／继续时保留进度、实际版本和队列；左侧序号常驻，曲名／歌手各一行。导航按钮使用已有右侧留白，靠近或键盘聚焦时显现，热区透传。侧面板实际占用自己的宽度，主列表滚动条保留；打开队列居中当前曲目，后续进度更新保留手动滚动。
- 跨歌单定位依赖可确认的音源 ID、原始歌曲身份或已注册本地文件身份。同名但身份不同的歌曲不会据标题推测；来源歌单保留实际位置，其他歌单重复时取第一处。当前歌曲被筛选隐藏时清空筛选再定位，暂停后仍可定位。
- 上下方向键在应用内非输入场景每次调整音量 5 个百分点，音量滑条获焦时使用相同步幅；输入、歌词滚动区域、其他滑条、弹窗和组合键保留原有行为。
- 歌曲缓存容量可设置为 512 MB–20 GB，按 1024 换算，默认 2 GB、单曲上限 512 MB。上限作用于当前目录的完整缓存，保护正在使用的文件并在释放后复核；旧目录及其未完成下载保留，重新启用旧目录时按当前容量清理。容量边界、淘汰和锁定失败使用隔离文件及统计替身验证，实际解码仍由生成 WAV 的桌面回归覆盖。

## 歌曲封面与同步歌词

- 歌单歌曲封面按当前显示版本获取，左下角和正在播放页按实际播放版本获取；试听不会改写歌单图片。原始酷狗歌曲图片与实际网易云候选分开绑定，避免不同专辑的图片混用。
- 图片按可见歌曲加载，同曲请求合并、并发最多 3 个；当前歌曲优先。歌曲图片缓存上限 256 MB，与音频缓存目录和容量分开，已有图片与歌词可复用。
- 正在播放页隐藏左侧导航；默认封面在左、歌词在右，展开纯文字队列后隐藏大封面。歌词逐行同步，不提供逐字着色；译文使用音源已有内容，缺译文仅显示原文，无时间戳时显示文本，纯音乐和缺歌词提供提示。
- 本地音频使用占位图并提示不提供在线歌词；搜索、版本对照、本地音乐列表和队列不新增歌曲图片。封面／歌词缺失或接口失败不会中断音频播放；第三方公开接口的可用性和译文覆盖不能由本机回归证明。

## 平台与发行

- 后台播放仅在用户开启后将关闭窗口改为隐藏到系统托盘；退出托盘菜单、软件更新及系统结束仍正常退出。托盘不可用时保留可见窗口。重启不自动播放。
- 历史“下一首播放”保留实际版本并插入队列当前位置之后，继续遵循当前播放模式：随机可能选中其他歌曲，单曲循环继续循环当前曲目。在线历史仍依赖音源可用性，本地历史要求文件未缺失或改变。
- 搜索页离开后清空本次结果，返回空白；已保存的搜索历史不受影响。旧请求可完成主进程缓存写入，但不能覆盖新页面结果。

- 本轮目标是当前 Windows 11 x64。Windows 10、其他电脑、ARM64 未实测；安装包未经代码签名。
- 显示比例检查使用 Chromium 的 100%、125%、150% 设备比例，记录实际像素比例与窗口布局；没有修改 Windows 全局显示设置，也未验证跨显示器移动。
- 安装验证使用隔离的测试标识、安装目录和无快捷方式配置，应用内容与交付版逐项比对。覆盖旧安装及正式快捷方式属于用户实际安装时的范围。
- 大曲库场景为 120 个歌单、6416 个曲目位置，其中单张 5000 首；测试结果只适用于这组规模和当前机器。
- 全局搜索为在线网易云音源搜索（每页 20 首，支持无限滚动加载），歌单内查找使用歌单右上角即时过滤；批量下载和多设备同步尚未实现。软件更新仅在用户点击后检查 GitHub Release；不做后台检查。Portable 资料可以随目录移动，但 Windows 加密会话换电脑或用户后可能需要重新登录，自选缓存与本地音频的绝对路径也可能需要重新选择。
